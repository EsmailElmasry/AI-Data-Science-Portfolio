#  - Unpinned torch/torchvision let pip grab whatever is newest at deploy
#    time. A newer torchvision can rename EfficientNet's internal layers,
#    which is exactly what breaks model.load_state_dict(...) with an
#    "EfficientNet" error. Keep this pair matched to whatever produced the
#    .pth checkpoint (retrain or re-export if you truly need a newer pair).
#  - "+cpu" wheels are far smaller than the default CUDA-bundled ones,
#    which avoids slow/failed installs on CPU-only hosting like Streamlit
#    Community Cloud.
